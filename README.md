# ClinicReception

![CI](https://github.com/influencejr/ClinicReception/actions/workflows/ci.yml/badge.svg)

Консольний застосунок реєстратора клініки: записує пацієнтів на перший вільний
час лікаря без перетину прийомів, переносить і скасовує записи, веде їхній стан
і показує завантаження лікаря за день.

## Варіант і автор

Варіант № 4 (ClinicReception). Вовк Давід Олександрович, група 471. Дисципліна
«Конструювання програмного забезпечення», 2026.

## Швидкий старт

```bash
git clone https://github.com/influencejr/ClinicReception.git && cd ClinicReception
dotnet build -c Release
dotnet run --project src/ClinicReception.App -c Release
```

Потрібен .NET SDK 8 або новіший. Дані беруться з теки `data` у корені
репозиторію; іншу теку можна передати аргументом після `--`.

## Структура рішення

| Проєкт | Призначення |
| --- | --- |
| `src/ClinicReception.Core` | бібліотека логіки: домен (запис, інтервал, добір слоту) і прикладний шар (сценарії, звіти, інтерфейси сховища) |
| `src/ClinicReception.Infrastructure` | файли JSON, довідники в пам'яті, журнал у файл |
| `src/ClinicReception.App` | меню, барикада вводу, композиційний корінь |
| `src/Legacy` | навчальний модуль ЛР 6, до застосунку не підключений |
| `tests/ClinicReception.Tests`, `tests/Legacy.Tests` | модульні тести xUnit |
| `data` | умовні довідники: 8 лікарів, 60 пацієнтів |

Шари й правило залежностей описано в [docs/architecture.md](docs/architecture.md).

## Можливості

Сценарії зі [специфікації](docs/spec.md): UC-01 записати пацієнта, UC-02
перенести або скасувати запис, UC-03 змінити стан прийому, UC-04 знайти записи
за пацієнтом, лікарем, періодом і станом, UC-05 звіт «завантаження лікаря за
день», UC-06 додати послуги й порахувати суму. Як ними користуватися - у
[посібнику](docs/user-guide.md).

## Тести й покриття

```bash
dotnet test -c Release /p:CollectCoverage=true /p:CoverletOutputFormat=cobertura /p:Threshold=70 /p:ThresholdType=line
```

Поріг 70 % рахується лише для бібліотеки логіки `ClinicReception.Core`
(параметр `Include` у проєкті тестів). Поточне покриття: 90,7 % рядків,
80,6 % гілок, 138 тестів. Конвеєр [CI](.github/workflows/ci.yml) виконує на
кожен push ту саму перевірку, що й ця послідовність команд:

```bash
dotnet format --verify-no-changes
bash scripts/check-source.sh
dotnet build -c Release -warnaserror
dotnet test -c Release /p:CollectCoverage=true /p:Threshold=70 /p:ThresholdType=line
```

## Обмеження й відомий борг

Записи зберігаються у файл лише під час виходу через пункт меню 0, тож аварійне
закриття втрачає зміни сесії. Довідники лікарів і пацієнтів редагуються лише
вручну у файлах JSON. Обідніх перерв і відпусток лікарів розклад не знає. Лист
пацієнтові лише друкується в консоль. У бібліотеці лишилися класи
лабораторних робіт (`Visit`, розрахунок ЛР 3), які застосунок не використовує.
