# Метрики ЛР 3: успадкований розрахунок вартості візиту

Об'єкт вимірювання — метод `LegacyVisitProcessor.Process`
(`src/ClinicReception.Core/Legacy/LegacyVisitProcessor.cs`, коміт `ba1a107`).
Складність рахувалася вручну за правилом методички:
ЦС = 1 + кількість точок розгалуження (`if`, `else if`, `for`, `foreach`,
`case`, плече switch-виразу, `catch`, `&&`, `||`, `??`, `?.`, тернарний оператор).

### Зв'язність і зчеплення

Метод має процедурну зв'язність: п'ять різнорідних обов'язків (перевірка входу,
підсумок послуг, знижки, зміна стану візиту, друк) об'єднано лише тим, що вони
виконуються один за одним, тому дібрати методу функціональну назву неможливо.

| Вид зчеплення | Де саме |
|---|---|
| за керуванням | параметр `printToConsole` вмикає гілку друку (рядок 85) |
| зовнішнє | 13 прямих викликів `Console.WriteLine`, з них 6 повідомлень про помилку |
| за даними (надлишкове) | 11 параметрів, з них 3 рядки поспіль (`patientName`, `patientEmail` і далі `promoCode`, `status`) легко переплутати |
| через вихідний параметр | `out string newStatus` повертає другий результат поза значенням методу |
